# 删除活动功能调试说明

## 问题诊断步骤

### 1. 打开浏览器控制台
- Chrome/Edge: 按 `F12` 或 `Ctrl+Shift+I` (Windows) / `Cmd+Option+I` (Mac)
- Firefox: 按 `F12` 或 `Ctrl+Shift+K` (Windows) / `Cmd+Option+K` (Mac)
- Safari: 先在 Safari 设置中启用"开发"菜单，然后按 `Cmd+Option+I`

### 2. 刷新页面并查看初始化日志
刷新页面后，在控制台中应该看到：
```
系统初始化...
活动列表: [...]
当前活动ID: ...
系统初始化完成
```

### 3. 尝试删除活动
1. 点击"管理活动"按钮
2. 找到要删除的活动
3. 点击"删除"按钮
4. 在控制台中查看输出：
   ```
   deleteActivity called with: activity-xxxxx
   Current activities: [...]
   ```

### 4. 可能的问题和解决方案

#### 问题1: 点击删除按钮没有反应
**原因**: JavaScript 错误或事件未绑定
**检查**: 
- 控制台是否有红色错误信息？
- 点击按钮时是否有 "deleteActivity called with:" 的日志？

**解决**: 
- 如果没有任何日志，说明按钮点击事件未触发
- 刷新页面（按 `Ctrl+F5` 或 `Cmd+Shift+R` 强制刷新）

#### 问题2: 提示"至少需要保留一个活动"
**原因**: 系统中只有一个活动
**解决**: 先创建第二个活动，然后再删除

#### 问题3: 提示"未找到该活动"
**原因**: 活动 ID 不匹配
**检查**: 控制台中的 "Activity not found:" 错误信息
**解决**: 清除浏览器缓存和 localStorage，重新开始

#### 问题4: 确认对话框未出现
**原因**: 浏览器阻止了弹窗
**解决**: 检查浏览器地址栏是否有弹窗阻止图标，允许弹窗

#### 问题5: 删除后活动仍然存在
**原因**: localStorage 未正确更新
**检查**: 
- 打开控制台，输入: `localStorage.getItem('activities')`
- 查看活动列表是否正确

**解决**: 
- 清除 localStorage: 在控制台输入 `localStorage.clear()`
- 刷新页面

### 5. 手动清除数据（终极方案）

如果以上方法都不行，可以手动清除所有数据：

1. 打开浏览器控制台
2. 输入以下命令：
```javascript
localStorage.clear();
location.reload();
```

这会清除所有数据并重新开始。

### 6. 验证修复

删除成功的标志：
1. 控制台显示完整的删除流程日志
2. 出现确认对话框
3. 点击确认后，看到成功提示："活动'XXX'已删除"
4. 活动管理列表中该活动消失
5. 如果删除的是当前活动，自动切换到第一个活动
